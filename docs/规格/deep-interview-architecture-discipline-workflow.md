# Spec: vibecoding 架构纪律工作流

> 本 spec 是 deep-interview-pure 的产物。13 轮 Socratic 压力测试后结晶。
> **不是又一份 AGENTS.md**——是独立工作流,定位为"让 vibecoding 本身不那么烂架构"。

---

## 元数据

- **profile**: standard
- **rounds**: 13
- **final ambiguity**: 0.11(threshold 0.20)
- **context type**: greenfield 设计,扎根 brownfield 证据(myshelltool 实测)
- **证据来源**:myshelltool 实测行数 + AGENTS.md 失效实证 + 8 篇业界文章 + find-skills 检索

---

## Intent(为什么需要这个工作流)

vibecoding 导致架构腐烂,**根因不是文件体积,是两个结构性事实**:

1. **AI 在时间上是局部的**——只对"本次会话"负责,没有维护架构的长期动机(维护收益在未来,而未来的它不是它)。
2. **人在协作回路里退化为"diff 盖章员"**——架构思考被外包给 AI,人从"架构师"退化成"需求下发员 + 盖章员",只能否决不能主动塑造。

**AGENTS.md 失效的实证**:myshelltool 的质量红线写了 500/800 行硬上限,`ssh.rs` 实测 2055 行(2.57×)。规则被违反 20 次无人察觉。连"重构候选清单"自身(手写 ssh.rs=1548)都腐烂了 500 行。**被动文档防不住温水煮青蛙式的累积腐烂。**

---

## Desired Outcome(目标态)

一套独立的 vibecoding 健康工作流,满足:

- **保留 vibecode 便捷性**(不被外部闸门切碎)
- **不靠记忆**(区别于 AGENTS.md 的"记得才查")
- **不变新 slop**(不退化成又一份清单)
- **AI 不可伪造自检**(机械信号兜底,非声明)
- **人可主动跳过**(但跳过时是清醒的)

---

## 核心设计(三层 + 分档 + 双重验证)

### 三层覆盖(按时间序列)

| 层 | 时机 | 动作 | 机制 |
|---|---|---|---|
| **上游:探索前置** | 写代码之前 | AI 先在"探索"模式看全仓(有什么/是否重复/放哪个层),再进入"写"模式 | 不拦你写,只迫使你写之前是清醒的 |
| **中游:drift 可见** | session 结束 | AI 产出本次改动的"架构增量报告":动哪些文件/离红线多远/是否疑似重复实现 | 不拦你写,只让 drift 可见 |
| **下游:信号超阈提议** | 累积信号触发 | 某些信号超阈(文件超 1.5× / 重复实现 ≥3 / import 链过长),AI 提议"该开重设 session" | 提议,不强制 |

### 风险分档(决定哪一层介入多深)

| 风险档 | 触发信号 | 走多深 |
|---|---|---|
| **低** | 改一个已有函数体、加文案、纯格式 | 纯 vibecode,啥都不跑 |
| **中** | 碰超限文件 80%、加新组件、动 ≥3 文件 | 只跑上游探索 |
| **高** | 引入新抽象(trait/store/领域层)、新建第二个同类实现、新建顶层目录 | 上游 + 中游 |
| **周期** | 累积信号超阈(下游触发) | 纯架构 session 重设 |

**核心**:**99% 的 vibecode 不被拖慢,只有 1% 真正危险的被拦**。这是保留便捷的唯一路径。

### 双重验证(命门,不可妥协)

| 阶 | 防什么 | 机制 |
|---|---|---|
| **一阶** | AI 偷懒不跑命令 | **机械信号**:AI 必须跑 `wc -l` / `grep` / import 扫描,**产出物内嵌原始命令输出**(非 AI 声明) |
| **二阶** | AI 刷指标 / 判断错 / 事后合理化 | **设计解释**:必须同时给出 (a) **锁指到具体代码**(复用 `sessions.js:142` 的 X,不是空谈"可维护性") + (b) **取舍面**(不这么做会怎样、被含掉的代价是什么) |

**机械信号兜底的具体形态**(Round 13 锁定):**结构化自检报告 + 内嵌原始命令输出**。报告里没有原始 stdout = 没自检 = 禁止进入下一步。

## In-Scope(这个工作流做什么)

1. 写代码前的探索前置(上游)
2. session 结束的 drift 增量报告(中游)
3. 累积信号超阈时提议架构重设(下游)
4. 按风险档决定介入深度
5. AI 自检时必须产出"报告 + 原始命令输出"作为不可伪造证据
6. 高风险档必须给出"锁指代码 + 取舍面"的设计解释
7. "引入新抽象 / 职责边界 / 语义重复"三类决策必须人批

---

## Out-of-Scope / Non-goals(明确不做)

- **不追求零 drift**:接受小 drift 累积,只在高风险档介入。追求零 drift = 每次走全套 = 你会嫌烦不用。
- **不拦你跳过**:你永远是最终裁决者,可随时说"这次跳过"。skill 的价值是让你**跳过时是清醒的**,不是"不能跳过"。
- **不取代需求澄清**:这是"vibecoding 时的需求完整性 + 架构最优"工作流,**与现有 deep-interview-pure 无关**(用户明确指示:不考虑 deep-interview,这是独立体系)。

---

## Decision Boundaries(AI 可自决 vs 必须人批)

**AI 可自决**:
- 机械信号查询(wc / grep / import 扫描的具体命令)
- 低/中风险档的完整执行
- drift 报告的生成

**必须人批**:
- 引入新抽象(新 trait / 新 store / 新领域层 / 新顶层目录)
- 职责边界的重新划分(把业务逻辑挪层)
- 语义重复的判定(是否复用已有实现 vs 新写一份)
- 跳过流程的最终决定

---

## Constraints(硬约束)

- 不破坏 vibecode 便捷性(单次 overhead 控制在可接受范围)
- 不依赖记忆(必须由触发器驱动,不是"记得才查")
- 不变成新 slop(不退化成清单 / 表格填空)
- AI 不可伪造自检(机械信号兜底)
- 工作流可被跳过,但跳过时必须明确(不静默绕过)

---

## Testable Acceptance Criteria

落地后,以下场景可验证:

1. **低风险**(加一个文案):AI 不跑自检,直接写。✅ 便捷保留。
2. **中风险**(改超限文件的函数):AI 动手前先跑 `wc -l <file>` / grep 类似实现,把原始输出贴进会话,再写。**没贴 = 违规。**
3. **高风险**(引入新 trait):AI 写出"锁指代码 + 取舍面"的设计解释,等你确认才动手。**解释里没有具体文件:行号 = 违规。**
4. **session 结束**:AI 产出 drift 增量报告(动了哪些文件、离红线多远、是否疑似重复)。**没报告 = 违规。**
5. **累积信号超阈**(某文件从超 1× 涨到超 1.5×):AI 提议开纯架构 session。**你可拒绝,但提议必须出现。**
6. **不可伪造测试**:让 AI 假装"我检查过了"。它必须能拿出 `wc -l ssh.rs` 的真实输出。拿不出 = 暴露。

## Assumptions exposed + resolutions(压力测试发现)

| 假设 | 压力测试轮 | 发现 / 解决 |
|---|---|---|
| "AGENTS.md + AI 自检就够" | R5 | **AGENTS.md 失效的根因正是 AI 不照做**。skill 作为"激活模式"(vs 参考)是唯一区别。命门 = 机械信号兜底 |
| "机械信号能防一切" | R6 | **机械信号只防偷懒,不防刷指标 / 判断错**。需二阶验证(设计解释) |
| "AI 解释可靠" | R7 | **AI 极擅长事后合理化**(SOLID / 设计模式张口就来)。解法:要求锁指代码 + 取舍面,二者缺一即虚 |
| "需求完整性该归 deep-interview" | R10 | 用户明确:**不考虑 deep-interview,这是独立体系**。需求完整性在本工作流内一等公民 |
| "应该加 pre-commit / CI" | R12 | 业界共识指向 pre-commit,但用户选**纯 AI 自检**。这是显式赌注:赌"激活模式 vs 参考文档"的差异够大 |

## Brownfield evidence(myshelltool 实测,作为设计证据)

| 证据 | 数值 / 事实 | 教训 |
|---|---|---|
| `ssh.rs` 行数 | 2055(上限 800,2.57×) | 红线被违反 20 次无人察觉 |
| AGENTS.md 重构候选清单 | 记录 ssh.rs=1548,实际 2055 | **连清单自身都腐烂 500 行** → 手写的数字必然过期 |
| 文档镜像数 | 5 份(AGENTS.md / CLAUDE.md / copilot-instructions / .cursor/rules ×2 / guidelines) | **规则被重复存储,全部从 AGENTS.md 派生,全部一起腐烂** |
| 可执行机制 | 零 CI / 零 pre-commit / 零 lint / 零架构测试 | 从"建议"到"强制"差最远的一步 |
| AI 凭印象误判 | 上一轮差点建议重写 sync.rs,实测 585 行未超 800 | **AI 凭印象做架构决策是危险的** → 必须机械信号兜底 |

## 残留风险(必须诚实告知)

1. **纯 AI 自检的赌注未经验证**——第一次落地时,你能否真的在每个高风险档停下来自检,未知。如果两周后开始跳过,本工作流重演 AGENTS.md 轨迹。
2. **机械信号覆盖不到抽象决策**——"该不该引入新 trait"靠你的二阶验证,你的判断质量决定这层的真实强度。
3. **下游"信号超阈提议"非强制**——AI 提议你可忽略,myshelltool 重构清单腐烂可能重演。
