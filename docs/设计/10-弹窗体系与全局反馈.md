## 1. 域概述与现状小结

**骨架现状**（引本域诊断 summary，并经本轮代码复核证实）：GlobalModals（24 种 modal type 的唯一宿主，标题 `modalTitles` / 提交 `modalSubmit` / 样式 `GlobalModals.modal.scss` 三件套，遮罩不关、Esc 对安全审批路由 deny、退场动画经 `useModalView` 滞留载荷）+ 新式 AppModal（SshImportDialog 等独立 overlay，带焦点圈）+ AppToastHost/toastQueue（4 级时长 3.5s/6s/8s、上限 5）+ AppContextMenu（终端/文件/侧栏/AppSelect 四消费方共用）。信息密度高、组件拆分与注释纪律好。

**双轨判据是本域的架构资产**（AGENTS.md §4.1）：简单确认类进 GlobalModals（新增 type 需同步 `src/lib/modalTitles.ts` 与 `src/lib/modalSubmit.ts` 两处）；自持复杂流程的新弹窗走 App 根级 overlay（AppModal + 独立 SFC，先例 SshImportDialog.vue，头注释登记理由——`SshImportDialog.vue:10-12` 登记的正是「GlobalModals 贴 500 行硬上限，新弹窗不往里塞」）。legacy 测试选择器 `#modalLayer`/`#modalBody`/`#modalPrimary`/`.modal-actions .btn.danger` 被 Playwright 实测依赖（`tests/ui-host-key.mjs:132,133,141,179`、`tests/ui-ipc-flows.mjs:455,854`，本轮 grep 实测），任何结构调整不得移除。

**本域用户反复处理的对象**（design-craft-console 第 0 步口径）：弹窗侧是「一次必须处置的决断」（看依据 → 判断 → 选动作 → 提交，处置一次 10 秒内、高频发生在建连闸口与文件操作）；反馈侧是「一条需要被看见的操作回执」。本域不是 workspace 整壳，而是叠加在工作台之上的决断层与回执层——它的设计目标不是「信息更多」，而是「决断更快、回执不打断、失败不丢失」。

**规模事实**（本轮实测）：`wc -l`——GlobalModals.vue 495 行（贴近 500 硬上限，RATCHET 只许缩不许涨）、modalSubmit.ts 273 行、modalTitles.ts 40 行、GlobalModals.modal.scss 337 行、SshImportDialog.vue 303 行、AppModal.vue 203 行、AppToastHost.vue 173 行、toastQueue.ts 77 行、AppContextMenu.vue 255 行。全仓 77 个 .vue（find 实测，与全局输入一致）。

**最大问题**：P0 一项——SshImportDialog 的 footer 按钮因 AppModal 无该插槽出口从未渲染（导入主操作不可达，见 §2 行 1）；其次是 GlobalModals 无焦点圈/初始焦点/焦点还原、安全审批 ×=拒绝语义不醒目、modal.scss 大量 token 外硬编码。全部为代码级证据；键盘/对比度实测未执行。

## 3. 逐界面方案定格

### 3.0 页面类型判定与覆盖登记

- **判定**（design-craft-layout-rhythm《布局适用范围》三类页面口径）：本域全部界面按内容归 **focused**——「单个表单/单个确认」的短打断面，无 workspace 整壳任务；toast 与右键菜单是瞬态浮层而非页面，不参与 workspace/focused 判分，按 design-craft-states §7 浮层纪律（选型表/必备清单/层级纪律）验收。各节不再重复判定，只给依据要点。
- **尺寸现状是资产，不引入新档**：确认类 GlobalModals 580px（modal.scss:31）、表单类 AppModal 默认 480px / SshImportDialog 640px（AppModal.vue:15、SshImportDialog.vue:136）、左导航面板型 760px（modal.scss:103）——与 design-craft-states §7.2 建议区间（确认 480–560/表单 640–720）基本吻合；760px 面板型超出表单档但承担的是「左导航+内容」双区结构（modal.scss:98-100 注释），登记为既成规格、不外推为通用上限。
- **覆盖登记**：无对 00 取值的覆盖。两处域内细则登记：
  1. 密度微调（00 §4.3 允许项）：`.stack/.grid-2` gap 10px → `--space-2`（8px）；`.context-grid` 6px 12px → `--space-1 --space-3`；`.callout` padding 10px 12px → `--space-2 --space-3`、圆角 6px → `--radius-sm`（8px）。理由：10px/6px 不在 4px 基线档（`_tokens.scss:138-140`），归最近档后仍在紧凑档语料区间「组件内 8-12」。作用范围：仅 GlobalModals.modal.scss 消费面。
  2. 圆角双轨现状登记（不改动）：GlobalModals `.modal` = `--radius-md`（modal.scss:28），AppModal `.app-modal` = `--radius-lg`（AppModal.vue:134）。与 00 §1.1 圆角语言对照（「卡片弹窗菜单 md / 大面板 lg」），两轨各自成立：GlobalModals=紧凑对话轨，AppModal=大流程面板轨。新增弹窗按所走轨道取既成值，不引入第三种。理由：双轨判据是 AGENTS.md §4.1 既定架构，取值随轨不随域。
- **特色申报**：本域特色使用 = **无**（00 §2.6 配额两点均不在本域；弹窗/菜单/toast 全部安静表面，无渐变/发光/大面积 accent）。

**焦点契约（A2，本域 P1 的核心修复）**——规则定格：

1. **初始焦点统一落「安全侧动作」**，优先级：① `data-modal-autofocus` 标记元素（安全审批类的「拒绝」钮打标）→ ② 第一个表单控件（表单类）→ ③ 「取消」钮（说明/确认类）→ ④ modal-body 容器（`tabindex="-1"`，纯说明无动作时）。判据：hostKeyVerify 信任主机=危险方向、拒绝=安全方向（AGENTS.md §8 红线：变更默认阻止）；与既有「Esc=拒绝」fail-secure 语义同源（useModalDismiss.ts:4-8 注释）。
2. **Tab/Shift+Tab 在弹窗内循环**不逃逸（AppModal.vue:34-53 的 focusable 选择器与翻转逻辑为蓝本，抽 `useModalFocus` 共用）。
3. **关闭还原焦点到触发元素**（AppModal.vue:76-78 的 isConnected 判空为蓝本）。
4. Esc 语义仍归 `useModalDismiss`（不重复监听；A2 composable 只管 Tab/初始/还原三件事）。
5. legacy 测试选择器不动：`#modalLayer/#modalBody/#modalPrimary` 保持原 id；拒绝钮补 `id="modalDeny"` 供初始焦点定位与将来测试（新增 id 不影响既有选择器）。

**未知 type 守卫（A7 的一部分）**：type 收字面量联合后，template 显式 `tokenConfig` 分支渲染 PatConfigCard；`v-else` 改为守卫卡——标题「提示」、正文「遇到未登记的弹窗类型（type），功能已继续，可安全关闭」+ 唯一动作「关闭」；dev 构建下 `announce` 一条 error 便于发现。判据：AGENTS.md 决策清单 7（分发优先注册表防散漏）+ 00 §3.6 错误文案四要素（发生了什么/影响=无/原因=未登记 type/下一步=关闭）。

**空态四分**：基座无空态消费面（弹窗必带内容）；守卫卡即「数据不存在/已删除」类的弹窗版（可能原因=未登记 type + 返回=关闭）。

**特色与克制**：无特色；scrim 单色、无渐变发光；accent 面积=主按钮一颗（<5% 合规）。

**非目标**：不改 24 型的分发机制（titles/submit/scss 三件套）；不动 legacy 选择器；不把 GlobalModals 迁移为 AppModal 轨（双轨是既定架构）；不新增全局 Esc 行为。

**验收方式**：键盘——打开每个弹窗 Tab 一圈不逃逸、初始焦点落安全侧、Esc 语义按类型（安全审批=拒绝）、关闭后焦点回触发钮；对比度——muted 标签与 form-error 文字在实际主题 panel 上 ≥4.5:1、焦点环 ≥3:1（实测未执行，待 tauri:dev 走查）；断点——800px 最小视口下 580px 弹窗左右边距 ≥110px、760px 面板型边距 20px（紧但可用，<1024 断点走查一次），断点折叠不影响弹窗居中（弹窗 fixed 层独立于 workbench grid）。
