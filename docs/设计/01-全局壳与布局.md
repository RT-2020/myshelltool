## 3. 逐界面方案定格

### 3.0 域级判定：页面类型与骨架选型

**页面类型：workspace**（三类页面判据，design-craft-layout-rhythm《布局适用范围》§三类页面）：本域是后台工作台——围绕工作对象组织一种主骨架，重复行（资产树行）、固定密度（紧凑档）与分栏是允许且必要的；不适用 long-form 的形式数量/间距配额，也非 focused 的单栏短页。判据落点：用户画像（运维/后端/SRE 每天长时间高频多会话操作，任务说明 Q1）、五区域 grid 既有骨架（`workbench-shell.scss:8-11`）、密度语言（状态栏 28px、树行 28-32px，00 §2.4 紧凑档现状）。

**控制台骨架选型**（design-craft-console §二，一屏一种主骨架）：

- 第 0 步找对象——主窗口壳：用户反复处理的对象是「**一个连接资产的会话**」；每小时处理次数为数十次量级（连接、看终端、传文件）；一次处理的动作链：找到资产 → 建连 → 终端操作 → 传文件 → 看监控。
- 主窗口壳 = **目录树型（#8）**：左树（资产按 group 分层，可折叠）+ 右内容（选中资产的会话工作台），键盘树导航已由既有实现承担；中央上终端下文件是内容区的内部分栏，右栏资源监控是**附属面板**（指标监看形态），不构成第二种主骨架。
- 资产窗口壳 = 目录树型选中节点后的**单对象详情形态**：树收起为零（窗口即一个资产），上终端/下文件双滚动区 + 右侧指标监看附属。
