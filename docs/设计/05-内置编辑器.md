## 1. 域概述与现状小结

**域范围**：`src/components/editor/` 下 5 个组件（EditorSurface / EditorTabBar / EditorToolbar / CodeMirrorHost / MarkdownPreviewPane）+ `src/stores/editor.ts`（444 行）+ `src/lib/editor/`（editorFlows.ts 422 行等）。弹窗形态挂载两处：主窗口 `WorkbenchShell.vue:381` 与资产窗口 `AssetWindowShell.vue:307`，均渲染于中央区之上（`EditorSurface.vue:5` 头注释「挂载于主窗口 / 资产窗口的中央区之上」）。

**行数基线**（`wc -l` 实测）：5 组件共 1233 行——EditorSurface.vue 448 / EditorToolbar.vue 191 / CodeMirrorHost.vue 279 / EditorTabBar.vue 170 / MarkdownPreviewPane.vue 145，全部低于 500 行硬上限（AGENTS.md 质量红线）。

**引诊断 summary**：内置编辑器为弹窗形态（遮罩+居中窗）四段式骨架：tab 条+工具栏+CM 主区/MD 预览分屏+状态栏。工程质量总体高：hover 铁律全合规（无 transition:all、dirty 圆点/关闭按钮常驻占位只改绘制属性）、编码切换与重载均有 dirty 确认兜底、GBK 重试与编码白名单（8 项，`editorCodec.ts:14-23`）链路完整、MD 预览过 DOMPurify（`MarkdownPreviewPane.vue:27-30`）。核心缺陷集中在两处：Markdown 预览内容通道无 tab 归属（跨 tab 串扰+清空回退旧文，P1）与关闭按钮 span 不可键盘聚焦（P1）；其余为 token 纪律与状态覆盖类打磨项。全部诊断为代码级证据，浏览器/桌面实测未做。

**域在产品中的定位**：文件面板双击文本文件直开（`editorLanguages.ts:14-19` TEXT_EXTENSIONS 名单命中即开）、拖入窗口打开（`EditorSurface.vue:91-110`）、路径输入打开（`editor.ts:362-395`）——是运维改配置、看日志的高频顺手工具，不是独立应用。单文件 ≤2 MiB、编码白名单严格转码、写回 expected 守护（AGENTS.md §9 既有边界）。

## 3. 逐界面方案定格

本域是**单一界面**：编辑器弹窗（EditorSurface 容器 + 4 个子区块组件）。以下按界面整体定格，子区块细则在 §3.6 状态矩阵与 §4 调整清单展开。

### 3.1 页面类型与依据

**类型：workspace。**

依据：
- 布局适用范围.md:10 对 workspace 的定义原文点名「后台、工作台、**编辑器**。围绕工作对象组织一种主骨架，重复行、固定密度与分栏是允许且常常必要的」——编辑器是 workspace 的指名成员，非 focused（focused 判据「短落地页、搜索入口、单个表单」均不符）。
- console SKILL 第 0 步找对象：**用户在这一屏反复处理的对象是一份打开的文件内容**（远端/本地的配置或文本文件）。动作链：打开（文件面板双击/拖入/路径输入）→ 读 → 改 → 校验/格式化 → 保存回原位置（expected 守护，AGENTS.md §9）。布局必须围绕这份内容生长——内容区面积最大（editor-main flex:1，EditorSurface.vue:291-296），其余三段（tab 条 34px / 工具栏紧凑 / 状态栏 26px）是安静外壳，符合该对象的工作方式。
- console §二 选型：**#6 分栏编辑器型**（一份内容边改边看）。排除：#4 主从型（无列表-详情关系）、#1 队列型（非串行处置）、#9 表单流型（非录入流程）。Markdown 分屏（编辑+预览两栏）正是 #6 的「边改边看」形态；非 markdown 文件时退化为单栏编辑，仍是同一骨架的退化而非第二种骨架。

| 类型 | 本域判定 |

## 5. openQuestions

1. **浅色焦点环对比度（A11）**：`--accent-soft-strong` 浅色 #cfdaff（_tokens.scss:88）在 `--app-panel` #fff 上的焦点环是否 ≥3:1，以及 CM 编辑区 caret+activeLine 的焦点可感知性——均需 Tab 走查 + 对比度测量，本轮无浏览器/桌面实测，未验证，不能声明结论。
