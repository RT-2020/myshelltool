## 1. 域概述与现状小结

本域是产品方向的主舞台：00 §2.1「终端是唯一主角，其余一切是安静的外壳」在本域的字面实现——恒深色画布（`--term-bg` 浅色主题下 `#0c0f17`、深色下沉 `#07090f`，`_tokens.scss:112,:235`）占据 main 区除 32px 标签条外的全部面积（`TerminalSurface.vue:307-317` grid `32px 1fr`）。

骨架（引诊断 summary，本轮逐条复核成立）：TerminalSurface 编排 32px 会话标签条 + 恒深色画布；搜索、速查表、命令面板、危险粘贴确认均为 body 级浮层（Teleport to body，`CommandPalette.vue:130`、`ShortcutCheatsheet.vue:52`、`DangerousPasteConfirm.vue:50`）；快捷键识别收敛于 `terminalGuards.ts` 单一信息源（`TerminalSurface.vue:87-88` 与 xterm 放行器共用 `matchAppShortcut`，`terminalGuards.ts:82-102`），危险粘贴守卫 fail-closed。底子扎实的部分：tablist roving tabindex（`TerminalTabs.vue:128-153`）、搜索三切换的 `aria-pressed`（`TerminalSearchBar.vue:65-67`）、命中计数 `aria-live=polite`（`TerminalSearchBar.vue:68`）、全局 `:focus-visible` 光环（`_base.scss:76-79`）、reduced-motion 组件自理（`TerminalSurface.vue:451-453`）、重名 tab 稳定后缀（`TerminalTabs.vue:186-191`）。

风险集中在**样式链断裂**而非结构：全局 `.btn` 类已不存在，但 `DangerousPasteConfirm.vue:69-70` 与 `TerminalSearchBar.vue:69-71` 仍在引用，危险确认的主按钮渲染为裸文本（`_base.scss:21-28` button reset 去 padding/边框）——这是本域最重的一个表现，安全确认的关键动作失去了按钮形态。另有死快捷键 Alt+Enter（速查表承诺、全栈无实现）、空态 CTA 无 hover、裸 z-index 5 处、白色 rgba 硬编码多处。**无 P0**；4 个 P1 中 3 个是「引用了不存在的样式」一类的确定性缺陷，全部可定位可修复，不涉及结构调整——因此本轮方案完全保留既有骨架与交互契约，不做 00 §2.6 之外的任何新特色。

**本域用户反复处理的对象（design-craft-console 第 0 步）**：一个活跃 SSH 会话。用户每个小时处理数十次，动作链是「确认当前会话是谁（看标签条）→ 读输出/敲命令（终端画布）→ 切到下一个会话（Ctrl+Tab 或点标签）→ 异常时处理失败（错误横幅）」。布局围绕这个对象生长：标签条回答「我是谁、还有谁」，画布承载全部实际工作，浮层只按需打断。

## 3. 逐界面方案定格

### 3.0 域级骨架：终端工作区（TerminalSurface 编排）

**页面类型：workspace**（依据 design-craft-layout-rhythm《布局适用范围》三类定义：本域「围绕工作对象（活跃 SSH 会话）组织一种主骨架，重复行（多 tab）、固定密度（32px 标签条）与分栏（五区域 grid）是必要而非装饰」；检查项——对象处理路径=「看标签条→读画布→切换」，滚动区=xterm viewport 独立滚动，空/满载状态=空态卡片/多会话溢出——全部有既有实现）。不是 focused：本域不是单表单短页；也不是 long-form：无叙事区块。整壳五区域（titlebar/sidebar/main/right/statusbar）属 workbench-shell 全局骨架（`workbench-shell.scss:8-11` grid-template-areas），本域只定格 main 区内部。

**console 十布局对照**：本域是「画布 + 顶部切换条」形态——对象是单一活跃会话、无「列表→详情」分屏需要，最接近 10 种中的画布型退化形态（对象无空间关系，不用画布；真正的骨架是既有 32px+1fr 两行 grid），**沿用既有骨架，不套用十布局中的任何新骨架**（方向纪律：既有骨架是资产）。

桌面线框（main 区，1366×800 基准；阅读顺序标 ①-⑥）：

│ ① 会话标签条 32px（tablist）                                         │
│ [+] [● 主机A (#a3f9) ×] [● 主机B ×] [○ 主机C ×]        [⋯ 更多]      │
├────────────────────────────────────────────────────────────────────┤

阅读顺序：① 当前会话是谁/还有谁（active tab + 状态点色）→ ② 终端内容（视觉主角，恒深色=全窗最深处）→ ③ 异常时错误横幅接管视线（danger 色，唯一允许抢注意力的元素）→ ④⑦⑧⑨ 按需浮层。该顺序与代码 DOM 序一致（`TerminalSurface.vue:204-270`）。

| ④ 搜索浮层 | 终端内容检索 | 画布内右上浮层，不挤压布局 |

字体角色（00 §2.3）：画布=xterm 终端角色（JetBrains Mono 13-14px，xterm 自渲染）；错误文案=数据角色（`--font-mono` + `--text-sm`，现状 `:381` 保留——错误串含路径/协议词）；标签条=标签角色（`--text-xs` 500，现状 `TerminalTabs.vue:370-377`）；浮层=正文角色（`--font-body` 400/500）。

**域级状态矩阵**（会话生命周期，状态点色为唯一「色通道」，文字通道由 tooltip/横幅承载——P5 双编码）：

| 会话状态 | 状态点 | tab 表达 | 画布表达 | 代码锚点 |
|---|---|---|---|---|
| connecting | `--warn` + pulse | 点脉动 | announce「正在连接：X」（状态栏） | `sessions.ts:289` |
| connected | `--success` | 点常亮 | shell 提示符可输入 | — |
| disconnected | `--app-subtle` | 点置灰 | 保留回滚缓冲 | `TerminalTabs.vue:169-175` statusFor |
| error | `--danger` | 点红 | ③ 错误横幅 role=alert | `TerminalSurface.vue:239-249` |

特色与克制：本域引用 00 §2.6 第 1 点「恒深终端区」，特色只由明度落差表达——标签条/错误横幅/浮层全部保持主题面板色，画布本体零 UI 装饰（现状水印网格与 ready 光标是画布内容的低干扰组成，aria-hidden，保留）。本域**不新增任何特色表达**。

**存量持续动画归类申报（接 00 §1.3 D4）**：`term-blink`（`TerminalSurface.vue:443-448`，ready-bar 1.1s steps(1) infinite）由本域正式登记为**终端区豁免**——它是终端光标固有行为（模仿 shell 光标闪烁的「终端就绪」语义），属终端内容语义而非 UI chrome 动效；且已满足 00 §2.5 持续动画的两条纪律：限等待/就绪态使用（`v-if="!activeSession"`，`TerminalSurface.vue:266`）+ reduced-motion 组件自理降级（`:451-453` 停格动画并 `opacity:1` 保留「就绪」语义）。travel（SyncStatusRail）归 sync 域，不在本域申报范围。

非目标（域级）：不做标签条分组/分色（多会话排序已有：Ctrl+Tab 循环 + 溢出菜单）；不做终端分屏（split pane）；不改 xterm 渲染参数；不做「关闭多标签确认」的产品决策（A15 只给形态建议，决策进 openQuestions）。

验收方式（域级）：`npm run build`（含 lint:facts，其中 no-box-model-in-hover 直接守 hover 铁律）+ `npm run lint:size` + `npm run test:ui`（smoke/host-key 两套直接覆盖本域）+ `npm run tauri:dev` 真桌面走查（SSH 连接浏览器不可验证，AGENTS.md §5）；键盘走查路径：Tab 进标签条→←→切 tab→Enter 激活→Ctrl+Tab 全局循环→Ctrl+F 搜索→Esc 收起→? 速查→Ctrl+Shift+P 面板（终端焦点外）；断点走查：<1280 标签条溢出折叠触发点提前（reserve 90px 逻辑 `TerminalTabs.vue:69-82` 随条宽自适应）、<1024/<860 画布占空比增大、右栏折叠不影响画布 grid（main 区行高不参与栏位折叠）。浏览器键盘路径与对比度实值未实测，落地后按 00 §5.2 补真实桌面走查记录。
